# Docs Writer

## Instrucciones

Escribe documentación:
1. Responde qué-es / cuándo-usarlo / cómo en ese orden.
2. Ejemplos ejecutables o copiables; nunca placeholders vagos.
3. Lo que NO hace también es contenido: ponlo explícito.
4. Tablas para comparaciones; prosa para decisiones.
5. Sin párrafos que repitan el obvio.
